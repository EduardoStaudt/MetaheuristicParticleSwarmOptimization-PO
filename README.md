# Metaheuristic Particle Swarm Optimization

Segundo seminário da disciplina de Pesquisa e Ordenação (CC4PO) da UTFPR Santa Helena. O trabalho é um estudo da meta-heurística Particle Swarm Optimization (PSO): como ela funciona, quais são suas variantes e onde ela é aplicada na prática.

## Conteúdo do repositório

```
.
├── index.html   página interativa com as simulações
├── docs/        slides da apresentação (.pptx)
└── README.md
```

## Página interativa

O `index.html` roda duas aplicações do PSO direto no navegador:

- **Rotas de drones:** três drones precisam chegar aos seus alvos sem atravessar obstáculos e sem se aproximar demais uns dos outros. Dá para arrastar obstáculos com o enxame rodando e ver as rotas se reorganizarem.
- **Corte de vidro:** o enxame procura a melhor ordem de corte das peças de um pedido de vidraçaria para gastar menos chapa. O pedido é editável e o corte final é animado.

Para usar, basta abrir o arquivo no navegador. Não precisa instalar nada.

Versão online: *[adicione aqui o link da Vercel](https://particleswarmoptimization.vercel.app/)*
